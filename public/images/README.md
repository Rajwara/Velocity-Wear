# Upload new images here

Name each file with its ID from `docs/Velocity-Wear-Image-Brief.pdf`
(for example `H01.webp`, `P05.webp`, `B03-F.webp`, `B03-T.webp`).

- Format: WebP (preferred) or JPG
- Use the exact pixel size listed in the brief for each ID
- Keep each file under 25 MB (GitHub's web upload limit); ideally under 300 KB

Once the images are here, they will be wired into the pages and the old template images removed.
